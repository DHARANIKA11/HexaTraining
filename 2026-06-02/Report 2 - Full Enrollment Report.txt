Report 1: Full Enrollment Report

 Objective

The Full Enrollment Report provides a consolidated view of learner enrollments by combining data from the learners, courses, instructors, and enrollments collections using MongoDB's `$lookup` operation. This report helps track learner progress, payment status, course details, and instructor information in a single view.

 Report Fields

* Enrollment ID
* Learner Name
* City
* Goal
* Course Name
* Category
* Instructor Name
* Payment Amount
* Payment Status
* Completion Percentage
* Enrollment Status

 MongoDB Query

javascript
db.enrollments.aggregate([
  {
    $lookup: {
      from: "learners",
      localField: "learner_id",
      foreignField: "learner_id",
      as: "learner"
    }
  },
  { $unwind: "$learner" },

  {
    $lookup: {
      from: "courses",
      localField: "course_id",
      foreignField: "course_id",
      as: "course"
    }
  },
  { $unwind: "$course" },

  {
    $lookup: {
      from: "instructors",
      localField: "course.instructor_id",
      foreignField: "instructor_id",
      as: "instructor"
    }
  },
  { $unwind: "$instructor" },

  {
    $project: {
      _id: 0,
      enrollment_id: 1,
      learner_name: "$learner.name",
      city: "$learner.city",
      goal: "$learner.goal",
      course_name: "$course.course_name",
      category: "$course.category",
      instructor_name: "$instructor.instructor_name",
      payment_amount: "$payment.amount",
      payment_status: "$payment.status",
      completion_percent: "$progress.completion_percent",
      enrollment_status: "$status"
    }
  }
])
